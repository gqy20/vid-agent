# 视觉风格指南 — 从"能跑"到"好看"

> `anti-patterns.md` 教怎么不崩，`geometry-math.md` 教怎么不偏心。
> 本篇教怎么让画面**专业**：配色语义、字号层级、屏幕分区。
> 全部按 **1080p 设计基准**（坐标系 14.22×8），与渲染分辨率解耦——
> 在 480p/720p 上验证视觉行为，1080p 上定稿（见 SKILL.md）。

## 配色：4 核心色 + 语义映射

教学动画的力量来自"颜色 = 意义"的**一致性**。别随手用色。全程同一变量 = 同一颜色。

| 角色 | Manim 常量 | Hex | 什么时候用 |
|------|-----------|-----|-----------|
| 已知 / 输入 / 原态 | `BLUE_C` | `#29ABCA` | 题设、给定值、初始对象 |
| 变换 / 变化 / 警告 | `RED_C` | `#E65A4C` | 正在改变的东西、变形过程 |
| 结论 / 结果 / 正解 | `GREEN_C` | `#77B05D` | 最终答案、正确状态 |
| 高亮 / 焦点 | `YELLOW_C` | `#F4D345` | 此刻要观众盯住的元素（瞬时） |
| 中性文字 | `WHITE` | `#FFFFFF` | 默认文字（深底） |
| 弱化 / 背景 | `GRAY_C` / `GRAY_D` | `#888888` / `#444444` | 已讲完、退到次要位置的对象 |

**规则：**

- 单场景**最多 4 个语义色**（不含 WHITE/GRAY）。多了等于没重点。
- 高亮（黄）是**瞬时**的——强调完恢复原色，别一直黄着。
- 弱化（灰）用来让"已讲完的对象退后"，给新焦点让位。
- 别用黄/浅蓝配白底（对比度不够，frame-check #11）。

## 字号层级（1080p 基准）

manim `Text(font_size=N)` 的 N 是像素高度（1080p 画布下，默认 48）。

| 用途 | font_size | 备注 |
|------|-----------|------|
| 大标题 / 收获帧 | 64–72 | 全屏标题、结尾 takeaway |
| 节标题 | 48 | 默认值；分区小标题 |
| 正文 / 公式主体 | 32–36 | 讲解正文、主公式（Unicode 上标，禁 MathTex） |
| 标注 / 标签 | 24–28 | `next_to` 贴着图形的标注 |
| 脚注 / 来源 | ≥ 24 | 低于 24 在 1080p 导出会糊（frame-check #10） |

**CJK 特别：** 中文笔画密，同字号视觉比英文"满"。中文正文建议 ≥ 32，标注 ≥ 26。
用 `Text`（Pango 渲染）——**别用** `Tex`/`MathTex`（无 CJK 且 spawn pdflatex，本环境必崩）。

```python
title = Text("勾股定理", font_size=64, color=BLUE_C).to_edge(UP)
body  = Text("a² + b² = c²", font_size=36).move_to([0, 0, 0])   # Unicode 上标，不是 LaTeX
label = Text("直角边", font_size=26, color=GRAY_C).next_to(a, DOWN, buff=0.1)
```

## 屏幕分区

把 14.22×8 的画布分成语义区，每 beat 只在主区放**一个**主导元素：

```
                y ≈ +3.5
   ┌──────────────────────────────────────┐
   │         TITLE ZONE   (y > 2.5)       │  节标题、beat 指示
   ├──────────────────────────────────────┤
   │                                      │
   │  LEFT     MAIN CONTENT   (|y|<2.5,   │  焦点公式 / 主图
   │  ANNO     |x|<5)                     │  观众视线落点
   │  x<-4                                 │
   ├──────────┬───────────────────────────┤
   │          │      RIGHT ANNO (x>4)     │  支撑信息：
   │          │                           │  给定值 / 结果 / 图例
   ├──────────┴───────────────────────────┤
   │         FOOTER ZONE   (y < -2.5)     │  字幕、来源、"第 N 步"
   └──────────────────────────────────────┘
                y ≈ -3.5
```

**区规则：**

- **Title zone**：只放一个短 Text，别放公式。
- **Main zone**：每 beat 单一主导元素。多对象用 `VGroup().arrange()`，别手摆坐标。
- **Annotation zone**：小字号（24–28）支撑标签，最多 3–4 个，多了乱。
- **Footer**：可选，克制用。

**布局优先相对 API**，别硬编码坐标（硬编码是 frame-check 里"飘到一块"的常见根因）：

```python
# ✅ 相对、可读、抗改动
steps = VGroup(t1, t2, t3).arrange(DOWN, aligned_edge=LEFT, buff=0.25)
steps.to_edge(LEFT, buff=1.0)
label.next_to(steps[0], RIGHT, buff=0.1)

# ❌ 脆弱、读不出意图、改一处全乱
t1.move_to([-5.13, 2.71, 0])
```

## 速查：按场景定调

| 场景 | 主色策略 | 布局 |
|------|---------|------|
| 概念讲解 | BLUE_C 主体 + YELLOW_C 焦点 | 居中主图 + 四角 callout |
| 证明推导 | BLUE_C 已知 → RED_C 变换 → GREEN_C 结论 | 左列步骤栈 + 右侧图形 |
| 函数图像 | WHITE 轴 + BLUE_C 曲线 + YELLOW_C 关键点 | 居中坐标系（`scale(0.85)` 留白） |
| 几何构造 | 多色区分对象 + YELLOW_C 当前关系 | 居中图形 + 外侧顶点标签 |

## 不确定时

少即是多。拿不准颜色 → 全 WHITE + 一个 YELLOW_C 高亮；拿不准布局 → 居中 + `to_edge(UP)` 标题。
**先把一个 beat 做干净，再加下一个**——和 SKILL.md 的 wall-clock beat 表一一对应。
