# 系列课程品牌包装

用于 Remotion 制作系列课程、技术课、品牌片头/片尾，以及 Remotion + Manim 混合成片。

## 三种开头/结尾不要混淆

- **全课程统一片头**：品牌级 intro，独立 composition，可拼到任意 episode 前面。例：`RefLightboxIntro`。
- **单集标题卡**：episode 内前 2 秒的主题标题。例：`EpisodeTitleCard`。它不是全局片头。
- **全课程统一片尾**：品牌级 outro，独立 composition，可拼到任意 episode 后面。例：`RefLightboxOutro`。
- **单集 takeaway**：本集内容收束，不等于品牌片尾。不要把 takeaway 做成下集预告板。

## 统一片头/片尾设计

片头和片尾应该是一套系统：

- 片头：从抽象系统展开到品牌与课程。
- 片尾：从抽象系统归位到品牌。

片尾建议做 **Concept Outro**，而不是订阅/预告/总结页：

```text
0-1.5s  概念节点散落或回收
1.5-3.5s  节点向中心归位，形成稳定系统图
3.5-4.8s  关键节点锁定，线条稳定
4.8-6s  品牌标题落版
```

片尾不要放：

- 下集预告
- 订阅 CTA
- 终端
- 多条 bullet 总结
- 大段正文
- 和品牌标题竞争的残留图形

## 最终落版必须是一个 lockup

最后 1 秒要把标题、标记线、小字当成同一个品牌 lockup，不要各自写散坐标。

做法：

- 定义统一中心线，例如 `lockup.centerX`。
- 中文标题、英文标题、横线、圆点、小字都围绕同一个 lockup 配置。
- 不要让标题按文字块坐标，底部圆点按画布中心坐标，否则视觉中心会漂。
- 最后品牌落版阶段只能有一个主视觉；前一层概念网络必须完全淡出或退场。

常见问题：

- 5s 附近圆圈重叠：通常是“概念网络节点”和“品牌横线节点”同时存在。修法是品牌落版开始后让概念网络 opacity 归零，而不是只降到半透明。
- 中文标题和底部圆点不齐：通常是标题组与底部标记组使用不同坐标体系。修法是建立 `lockup` 对象统一 x/y。

## Remotion / Manim 分工

先判断镜头表达是否适合某种工具，再看本地有没有现成组件。不能因为本地没有 Manim 场景，就把适合 Manim 的抽象模型降级成静态 SVG。

Remotion 负责：

- 课程包装、片头、片尾、进度条
- 字幕、终端、代码、diff、文件树
- UI 状态流转，例如 Working Tree / Index / Repository
- 轻量 Git 图、ref 写入、HEAD/branch 指针
- Manim 素材合成和最终剪辑

Manim 负责：

- blob/tree/commit 对象关系
- DAG、parent chain、merge/rebase/reset 这种拓扑关系
- 快照流、hash、内容寻址等抽象模型
- 需要构建期几何检查的节点、箭头、标签

如果镜头适合 Manim 但本地没有场景，应在制作文档中列为新增资产：

```text
scripts/manim/<course>/scenes/<scene_name>.py
```

## 外部图片和网络素材

课程优先用自制 Remotion/Manim 图形。只有这些情况才考虑外部图片：

- 需要真实界面或真实产品截图。
- 需要历史语境或官方来源佐证。
- 自制图会降低理解效率。

使用外部素材必须在分集文档说明：

- 用途：为什么需要真实图片。
- 来源：URL、截图方式或许可。
- 存放：`public/<course>/assets/<episode-id>/`。
- 替代：无法使用时如何用 Remotion/Manim 重绘。

不要把网络图片当装饰背景。外部素材必须服务解释。

## 抽帧检查

统一片头/片尾和每个课程片段,默认先从 encoded mp4 按**每秒 2 帧**抽连续帧:

```bash
.claude/skills/remotion-vid/scripts/check-frames.sh --video out.mp4 /tmp/check
```

contact sheet 每页最多 5 帧,保证能看清字幕、箭头、节点和小字重叠。

如果只做片头/片尾的锁点复核,还要额外看这些关键帧：

- 0s：是否空白或突兀。
- 25%：节点/线条是否重叠。
- 50%：系统图是否读得懂。
- 80%：品牌落版是否开始清场。
- 最后一帧：标题、标记、小字是否同轴对齐。

检查重点：

- 最后一秒不能有两套主视觉。
- 所有残留网络节点必须完全退出或降到不可见。
- 中文标题和下方标记用同一个 lockup 坐标体系。
- 不要只看视频能不能渲；必须看抽帧语义和布局。
