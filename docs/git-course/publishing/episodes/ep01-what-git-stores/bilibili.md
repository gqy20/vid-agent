Git 到底存了什么？先别急着背命令

## 简介

很多人一开始学 Git，会把它理解成“保存了很多个文件夹版本”。

这一集先不讲命令，先把 Git 的底层模型讲清楚：Git 保存的不是 `project`、`final`、`final-2` 这种文件夹副本，而是一组可以被 hash 校验、可以互相引用的对象快照。

先把这个模型建立起来，后面再学 `add`、`commit`、`branch`、`HEAD`，就不会只是在背命令。

## 你会学到

- 为什么 `project / final / final-2` 不是可靠的版本管理方式
- Git 为什么不是简单保存一堆文件夹副本
- `blob`、`tree`、`commit` 大致分别代表什么
- hash 为什么能让 Git 判断内容有没有变化
- 后面学习 `add`、`commit`、`branch` 时应该带着什么模型去理解
