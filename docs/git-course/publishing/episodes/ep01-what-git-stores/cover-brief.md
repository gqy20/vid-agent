# EP01 封面 Brief

## 目标

让观众在一秒内看懂本集问题：

```text
Git 不是在保存 final-2 这种文件夹副本，它保存的是可以被追踪和校验的对象快照。
```

## 主视觉

画面采用强冲突左右对照：

- 左侧：巨大主标题加一个被否定的 `final-2.zip` 错误动作；主视觉是打开的 `final-2` 文件夹，周围散落 `project`、`final`、`final-final`、`backup-old` 等手工备份碎片；封面只保留红色副标题这一处 `.zip`。
- 右侧：`.git/objects` 作为对象区域标题，使用贴纸式节点网络表现 `commit`、`tree`、`blob`，节点内保留短 hash 标识。
- 中间用大号 `≠` 表达：文件夹副本不等于 Git 的对象快照。

## 视觉要求

- 标题必须大，移动端缩略图也能读清。
- 不堆命令行截图，封面只讲一个冲突。
- 使用有趣的物体海报语言：奶油底、番茄红、芥末黄、深墨绿和青绿。
- 文件夹要是明确主物体，不要只是 UI 卡片。
- 右侧对象结构要比左侧更稳定、更有秩序，传达“模型被建立起来”。
