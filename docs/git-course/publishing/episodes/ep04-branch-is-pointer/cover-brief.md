# EP04 封面 Brief

## 目标

让观众在一秒内看懂本集问题：

```text
分支不是一份项目副本。分支只是一个名字，指向某个 commit。
```

## 主视觉

画面采用强冲突左右对照：

- 左侧：三个倾斜堆叠的"项目副本"文件夹（my-project / my-project-v2 / my-project-copy），笨重、混乱，配便签"复制了整个项目？"——代表被否定的误解。
- 右侧：一条 C0 → C1 → C2 的提交链，`main` 和 `feature` 两个指针标签都指向 C2，配便签"两个名字，都指向 C2 / 没复制任何东西"。
- 中间用大号 `≠` 表达：项目副本不等于轻量的分支指针。

## 文案层级

一级标题：

```text
Branch 不是项目副本
```

二级标题：

```text
它只是一个指针
```

角标：

```text
看得见的 Git
EP.04 · branch pointer
```

## 视觉要求

- 左侧副本堆要"笨重"，右侧指针要"轻"，对比传达"创建分支没有复制"。
- `main` 与 `feature` 必须都明确指向同一个 commit，把"两个名字、同一个 commit"讲清楚。
- 右侧提交链要比左侧更稳定、更有秩序。
- 标题大，移动端缩略图可读；不堆命令行截图，封面只讲一个冲突。
