# EP04 封面 Brief

## 目标

让观众在一秒内看懂本集问题：

```text
分支不是一份项目副本。分支只是一个名字，指向某个 commit。
```

## 主视觉

画面采用小尺寸优先的强冲突对照：

- 上半屏：左侧用超大红色 `branch` 作为第一视觉焦点，右侧两行中文判断；视觉阅读顺序与“branch 不是项目副本”的语序一致。
- 下半屏左侧：只保留一个标有"项目副本"的文件夹，代表被否定的误解。
- 下半屏右侧：极简 commit 链，`main` 和 `feature` 两个标签都指向同一个 commit。
- 中间用大号 `≠` 表达：项目副本不等于轻量的分支指针；去掉副本堆、便签和 commit 编号。

## 文案层级

一级标题：

```text
Branch 不是项目副本
```

二级标题：

```text
它只是一个指针
```

角标：

```text
看得见的 Git
EP.04 · branch pointer
```

## 视觉要求

- `branch` 必须是最大单一文字块，中文问题句退居第二层。
- 左侧文件夹要"笨重"，右侧指针要"轻"，对比传达"创建分支没有复制"。
- `main` 与 `feature` 必须都明确指向同一个 commit，把"两个名字、同一个 commit"讲清楚。
- 右侧提交链要比左侧更稳定、更有秩序。
- 移动端缩略图只需读出标题、`≠` 和两个模型，不展示解释性小字。

## 候选标题

```text
为什么创建分支这么快
```

```text
branch 到底复制了什么
```

```text
分支不是复制一份
```
