# EP03 封面 Brief

## 目标

让观众在一秒内看懂本集问题：

```text
commit 不是保存按钮，它是 Git 历史里的一个对象：指向项目快照，也指向过去的 parent。
```

## 主视觉

画面采用小尺寸优先的强冲突对照：

- 上半屏：左侧用超大红色 `commit` 作为第一视觉焦点，右侧两行中文判断；视觉阅读顺序与“commit 不是保存按钮”的语序一致。
- 下半屏左侧：只保留一个经典软盘保存图标，代表被否定的误解。
- 下半屏右侧：极简 commit 对象卡片，只保留 `tree`、`parent` 两个方向。
- 中间用大号 `≠` 表达：保存按钮不等于 commit 对象；去掉按钮、便签、hash 和 message 等缩略图不可读信息。

## 视觉要求

- `commit` 必须是最大单一文字块，中文问题句退居第二层。
- 软盘要明确是"保存"语义，一眼认出。
- 右侧对象卡片只用 `tree` 青绿、`parent` 番茄红表达两个指向。
- 移动端缩略图只需读出标题、`≠` 和两个模型，不展示解释性小字。
