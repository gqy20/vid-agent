# EP01：Git 到底记录什么

## 核心句

Git 保存的不是一堆手动复制的项目文件夹，而是一条可以追踪的快照历史。

## 观众要带走的理解

- 版本控制的目标是记录历史、比较变化和恢复状态。
- 复制文件夹保存版本容易混乱，因为它缺少清晰的历史结构。
- Git 更像是在保存项目随时间变化的一系列快照。
- 本地仓库保存完整历史，所以很多 Git 操作不需要网络。
- hash 让 Git 能用内容身份验证数据。

## 镜头结构

1. 提问：Git 到底记录什么？
2. 展示复制文件夹式备份的混乱。
3. 抽象出版本控制的三个价值：回退、比较、追踪。
4. 展示 Git 的快照流模型。
5. 用 `git log` 连接本地历史。
6. 用 hash 解释内容身份。
7. 收束：Git 保存快照历史，下一集进入三层状态。
