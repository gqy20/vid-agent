# EP01 voiceover design

本文件是 EP01 的口播设计源。修改配音文稿前，先改这里，再同步到
`remotion/renders/git-course/ep01-what-git-stores/renders/current/audio/voiceover_segments/*.txt`。

目标不是把每段塞满，而是让每一句都解释当前画面正在发生的事。

## TTS policy

- model: `speech-2.8-hd`
- voice: `Chinese (Mandarin)_Gentleman`
- language: `zh`
- speed: `1.25`
- 同一集必须整集重生，不能混用不同 voice 或 speed。
- 停顿优先使用 `<#0.2#>`、`<#0.25#>`、`<#0.35#>`；只在段落转折或画面换主视觉时使用 `0.45s` 以上停顿。
- MiniMax Speech 2.8 支持自然语气标签和口语填充词。课程里只允许少量使用，用于“纠错、转折、提醒观察”，不能把技术讲解变成闲聊。

允许的语气手段：

| 手段 | 用法 | 限制 |
|---|---|---|
| `嗯` | 轻微转折，表示“先看这里” | 每集最多 1-2 次 |
| `注意` | 纠正误解或引入核心概念 | 优先于口头禅 |
| `(breath)` | 段落开头或关键结论前的自然吸气 | 先做单段试听，不直接全片使用 |
| `(sighs)` | 表达“复制文件夹很混乱”的轻微无奈 | 仅可用于 bad-model，默认不用 |
| `(clear-throat)` | 正式开始或切换到定义前 | 教学视频默认不用，除非试听自然 |

## Adjustment rules

1. 如果某段越界，先看本表中标记“当前过密”的 beat，压缩对应句子，不随机删别处。
2. 如果画面还有空白，不优先加新知识点；先补“观察画面”的桥接句，比如“注意这里没变的文件”。
3. 语气词只放在纠错点：`复制文件夹`、`快照不是粗暴复制`、`不是相信文件名`。定义句不要加。
4. 每次生成后，把 `.srt` cue 反填到 `alignment.md`；如果 cue 和 visual beat 错位超过 1.5s，就改文稿或 manifest。
