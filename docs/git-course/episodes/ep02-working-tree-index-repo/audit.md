## 预渲染检查清单

- 三层状态面板必须是本集主视觉。
- `git add` 必须表达为“暂存当前内容”，不能只说“添加文件”。
- add 后继续编辑的段落必须清楚展示 `Index v1` 与 `Working Tree v2`。
- commit 必须读取 Index，不应错误地读取 Working Tree 当前内容。
- 不讲 blob/tree/commit object 结构，留给 EP03。
