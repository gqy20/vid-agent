# Reference Sources

## Pro Git

Official site: https://git-scm.com/book/

The Pro Git book is available under the Creative Commons Attribution Non Commercial Share Alike 3.0 license. The official site links the source to GitHub and the repository explains how to build HTML, EPUB, MOBI, and PDF outputs from the AsciiDoc files.

Local copies:

- `progit2/`: English source, shallow clone of `https://github.com/progit/progit2.git`, commit `a013e32`
- `progit2-zh/`: Simplified Chinese source, shallow clone of `https://github.com/progit/progit2-zh.git`, commit `e5c1da8`

Recommended use for the Git course:

- Use `progit2-zh/*.asc` for Chinese terminology and chapter structure.
- Use `progit2/*.asc` as the source-of-truth cross-check when a translated phrase is ambiguous.
- Treat chapters 2, 3, 7.6, 7.7, and 10 as the main source material for visual lessons about staging, commits, branches, merge/rebase, reset, references, and Git objects.
