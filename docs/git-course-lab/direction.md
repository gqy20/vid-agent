# Git Course Lab 方向

> 历史实验记录：其中的 Manim 分工已退出 Git Course 现行生产流程；当前课程抽象模型统一由 Remotion 实现。真实终端录制部分仍可作为参考。

`git-course-lab` 是 Git 课程的新表现范式验证区，不直接替换现有 `git-course`。

目标是验证三件事：

- 真实终端录制是否能提供比手写假终端更强的可信感。
- Manim 是否能把 Git 抽象模型做成逐步构造的解释动画。
- Remotion 是否只做合成、字幕、音频和包装后，画面会更干净。

## 表现原则

### Remotion 负责

- 成片时间线。
- 片头片尾。
- 真实终端录屏嵌入。
- Manim 片段嵌入。
- 旁白字幕、进度条和声音。
- 最终渲染、抽帧审查。

Remotion 不再负责手写主要 Git 概念图，也不再长期展示终端、状态面板、字幕和顶部标题。

### Manim 负责

- commit、tree、blob、branch、HEAD 等抽象对象。
- 对象之间的箭头、变形、复制、收束和展开。
- 快照流、DAG、内容寻址、三路合并等需要几何关系的解释。

Manim 场景应该低文字、高结构。每个镜头只构造一个核心关系。

### 真实终端负责

- 展示真实命令和真实输出。
- 作为概念动画的触发证据。
- 不承担长时间讲解。

终端出现时可以全屏。命令完成后终端缩小或退出，概念对象成为主视觉。
