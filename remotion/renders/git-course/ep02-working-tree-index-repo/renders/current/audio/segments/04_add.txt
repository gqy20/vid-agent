执行 git add app.js。<#0.25#>Git 会读取 app.js 此刻的内容，把这个版本放进 Index。<#0.35#>

这里进入 Index 的是当前版本，也就是 v1。<#0.25#>它不是跟随 Working Tree 自动同步的镜像。

所以 add 之后，<#0.25#>Working Tree 里仍然有正在编辑的文件，Index 则保存刚刚选中的 v1。<#0.3#>

add 更准确的意思是：<#0.25#>把文件此刻的内容，选进下一次提交。<#0.3#>

Repository 这时仍然没变。<#0.25#>因为 add 只是在准备下一次快照，<#0.25#>并没有写入历史。
