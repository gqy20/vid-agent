# EP02 segmented voiceover alignment

EP02 reuses the EP01 BGM at `audio/bgm.mp3`. BGM is mixed at fixed `volume=0.05`; no ducking is used.

Each voice segment is generated separately with MiniMax TTS, using inline pause markers such as `<#0.25#>`. The final aligned voiceover uses the `_norm.mp3` files, normalized with FFmpeg to roughly `-20 LUFS` and limited near `-3 dBFS`.

| Segment | Scene window | Voice starts | Normalized voice duration | Voice ends |
| --- | ---: | ---: | ---: | ---: |
| `01_hook` | 0.0-12.0s | 0.3s | 11.40s | 11.70s |
| `02_three-areas` | 12.0-38.0s | 12.4s | 21.98s | 34.38s |
| `03_modify` | 38.0-68.0s | 38.4s | 25.94s | 64.34s |
| `04_add` | 68.0-104.0s | 68.4s | 31.66s | 100.06s |
| `05_edit-after-add` | 104.0-134.0s | 104.4s | 25.98s | 130.38s |
| `06_commit` | 134.0-164.0s | 134.4s | 25.90s | 160.30s |
| `07_takeaway` | 164.0-180.0s | 164.2s | 14.85s | 179.05s |

Total normalized narration duration is about 157.7s in the 180s main episode. End-of-scene narration gaps are now about 0.3-3.9s per segment, with the tightest remaining gap in `01_hook` at about 0.3s.

Sentence-level timing is available in the sibling `.srt` files. Absolute sentence time is calculated as:

```text
absolute sentence time = Voice starts + cue time in segment .srt
```

Note: raw `.srt` files generated by MiniMax may keep speech tags such as `(breath)`. These tags are acceptable in TTS source text but must be stripped before burning subtitles into video.
