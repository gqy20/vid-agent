# cc-insights promo creative brief

## Audience

Developers and engineering leads who already use Claude Code enough that usage cost, repeated failures, and long sessions have become operational problems.

## Promise

cc-insights turns local Claude Code traces into root-cause evidence and the next command to run.

## One Pain

Claude Code usage feels expensive and slow, but the raw JSONL history is too noisy to explain what is actually wasting time.

## One Aha

The product does not just rank usage. It connects failures, sessions, tools, tokens, and commands into a diagnosis.

## Proof

Use real dashboard screenshots, concrete failure clusters, token/session tables, and CLI commands. The screen proves details; titles state conclusions.

## Visual Motif

Local trace pipeline:

1. JSONL noise
2. CLI ingestion
3. session graph
4. finding card
5. dashboard drilldown
6. next command

## Repetition Rule

Every beat must separate the three channels:

- Voice says the implication.
- Screen shows evidence.
- Text names the takeaway.

Do not repeat the same number in all three channels. If the voice says `7.8B Token`, the screen may show the table, and the title should say why it matters.

## CTA

End on a runnable command and repository URL. The final line should feel like a developer can copy it now.

## Avoid

- Feature-list pacing
- Tiny UI text as the main message
- Dashboard screenshots without a highlighted reason to look
- Decorative glitch that hides evidence
- Hero text that repeats the visible screenshot
